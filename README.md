# Tips for Mendix

A collection of practical guides for building, deploying, and managing Mendix applications and related low-code solutions.

---

## Guides

### Development

- [Microflows](./microflows/) -- Server-side visual logic: activities, decisions, error handling, and performance
- [Nanoflows](./nanoflows/) -- Client-side logic, offline support, and JavaScript actions
- [Entities](./entities/) -- Domain modeling, associations, access rules, and data patterns
- [Pages and UI](./pages-and-ui/) -- Layouts, widgets, styling, accessibility, and UI patterns
- [Integrations](./integrations/) -- REST, OData, SOAP, messaging, and external service connectivity

### Architecture and Operations

- [Modules](./modules/) -- Module structure, organization, security, and refactoring
- [Marketplace Modules](./marketplace/) -- Evaluating, installing, customizing, and maintaining third-party modules
- [Core Infrastructure](./infrastructure/) -- Runtime architecture, database, caching, clustering, and monitoring
- [Deployment Strategy](./deployment/) -- Docker, Kubernetes, Mendix Cloud, on-premise, and multi-environment setups
- [CI/CD](./ci-cd/) -- Build automation, testing pipelines, deployment automation, and quality gates

### Security and Compliance

- [Security](./security/) -- Authentication, authorization, API security, encryption, and hardening
- [SSO](./sso/) -- SAML payload validation and load balancer troubleshooting
- [Compliance](./compliance/) -- GDPR, CCPA/CPRA, ITAR, EAR, SOC, ISO, and Colorado Privacy Act
